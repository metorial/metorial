# <img src="logo.png" height="20"> Listen Notes

Search podcasts and episodes, retrieve detailed metadata and available transcripts, browse curated lists, and discover recommendations. Match episodes by title and platform-specific podcast identifiers, or discover shows by publisher domain. Create and update Listen Later playlists, manage their podcast and episode items and notes, and remove collections when needed. Submit podcast RSS feeds or request removal from the directory.

Use an API key from the [Listen Notes API Dashboard](https://www.listennotes.com/api/dashboard/). Search pagination limits and some metadata fields depend on your plan. Playlist writes require ownership by the API admin account. The optional test server returns synthetic data.

See [the API specification](docs/SPEC.md) and [official documentation](https://www.listennotes.com/api/docs/) for capabilities and limits.
