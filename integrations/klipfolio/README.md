# <img src="logo.png" height="20"> Klipfolio

Manage Klipfolio Klips dashboards, visualizations, data sources and stored data downloads. Discover users, roles, groups and agency clients; manage dashboard access and password-protected published links. This integration uses the Klips REST API, not the separate PowerMetrics APIs.

API keys inherit the permissions of their issuing user. Connector requests, user/client provisioning and publication can consume plan allowances or affect external services and access. Refresh requests are queued; check instance refresh status for completion. Connector property names are available, while their values are concealed to protect credentials.
