# <img src="logo.svg" height="20"> Kickbox

Verify email addresses for deliverability, detect disposable, role-based, and free email domains, and identify typos in email addresses. Supports single real-time email verification, batch verification, and checking the available verification credit balance. Returns deliverability status (deliverable, undeliverable, risky, unknown), a Sendex quality score, and suggested corrections for misspelled domains. Completed batch results are available as a downloadable CSV.

Connect with an API key from API Settings in the Kickbox dashboard. For mock verification results, connect with a Sandbox API key beginning with `test_`. Enabling the sandbox setting requires that key type and prevents requests with a live key; the API key determines whether Kickbox returns sandbox results.
