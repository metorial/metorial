# <img src="logo.svg" height="20"> TomTom

Search and reverse-geocode addresses and places, recognize autocomplete query terms, discover POI categories, calculate routes and route matrices, optimize waypoints, and retrieve real-time traffic flow and incidents. Calculate reachable ranges with time, distance, fuel, or energy budgets and match GPS traces to roads. Existing tools also manage geofencing projects, fences, alerts, tracked objects, location history, and notification contact groups.

Geofencing, Location History, and Notifications are scheduled for decommissioning on January 31, 2027. TomTom does not document a migration path. Search, Routing, Traffic, and Snap to Roads use their existing documented API versions.
