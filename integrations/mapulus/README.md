# <img src="logo.png" height="20"> Mapulus

Discover maps and layers, create and update locations, retrieve their details, and manage custom attributes. Find nearby locations by address or coordinates, choose a travel profile, and add travel time boundaries. Studio list tools return the first page of results; nearest searches return up to 24 candidates. An optional radius filters those candidates using source coordinates.

See [the API specification](docs/SPEC.md) for supported requests and current limitations.
