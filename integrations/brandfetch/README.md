# <img src="logo.png" height="20"> Brandfetch

Retrieve company brand assets and firmographic data by domain, website URL, email address, Brand ID, ticker, ISIN, or cryptocurrency symbol. Search brands by name, resolve transaction descriptors to merchant brands, and create logo URLs for direct embedding. Retrieve brand context covering positioning, products, audiences, voice, visual style, and competitors. Verify the connected credential and inspect API credit usage.

An API key authenticates the Brand API, Brand Context API, Transaction API, and Viewer API. An optional Client ID authenticates Brand Search and Logo URLs. Logo URLs are for direct embedding; the provider requires hotlinking and restricts programmatic image downloads. The integration does not register webhooks.

See [the API specification](docs/SPEC.md) for capabilities, response compatibility notes, and official documentation.
