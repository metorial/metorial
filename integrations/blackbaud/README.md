# <img src="logo.svg" height="20"> Blackbaud

Manage Raiser's Edge NXT fundraising data through Blackbaud's SKY API. Search, read, create, and update constituents and contact details; retrieve giving summaries; list, read, and create gifts; list, create, update, and read actions; inspect fundraising opportunities, campaigns, funds, and appeals; and retrieve saved constituent, gift, action, and opportunity lists.
