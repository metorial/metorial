# Similarweb Digital Rank API

Retrieve global, country, and industry rankings for website domains. List the top-ranked websites worldwide, check account credits, and discover available countries and historical date ranges before choosing filters.

## Tools

- `get_website_rank`: Retrieve global or country rankings by month, or the latest industry category and rank. Omit both dates for the last 28 days of global or country rankings.
- `get_top_websites`: Retrieve up to 5,000 globally ranked websites across desktop and mobile web traffic.
- `get_remaining_credits`: Check account-level remaining credits without consuming credits.
- `get_capabilities`: Discover subscription datasets, available countries, historical date ranges, and account credits without consuming credits.

## Authentication

Use an active Similarweb API key. Account admins can generate a key under Settings > Account > API > Standard API / Batch API. Available data and credit pricing depend on your subscription.
