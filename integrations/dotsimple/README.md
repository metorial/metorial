# Dotsimple

Create, schedule, publish, and manage social media posts across multiple platforms including Facebook, Instagram, LinkedIn, X/Twitter, TikTok, Pinterest, YouTube, and Mastodon. Manage connected social accounts, upload, browse, download, and delete media files, create and organize tags with custom colors, and retrieve account-level analytics reports. Supports platform-specific post options (e.g., TikTok privacy, YouTube visibility, Instagram post type), bulk post deletion, publishing queues, and viewing autoresponder configurations.

## Setup

Create an access token in DotSimple Settings > Access Tokens. Workspace IDs come from the workspace URL, `https://app.dotsimple.io/app/<workspace-id>`. Supply `workspaceId` with a tool call or save an optional default in connection settings. Existing saved workspace settings continue to work.

## Capabilities

The 18 tools cover post creation, retrieval, updates, scheduling, queueing and deletion; connected account listing and lookup; media listing, lookup, download and upload; tag creation, listing, lookup and deletion; and existing reports/autoresponder listings. The API documentation does not currently publish a current-user or workspace discovery endpoint.
