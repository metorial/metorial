# Delighted

Delighted is discontinued. The provider ended the product on June 30, 2026 and terminated customer access on July 1, 2026. The 12 legacy tools and their input/output fields remain for saved workflow compatibility, but every invocation fails before credentials are read or any provider request is made. New connections and profile lookups are also unavailable.

Do not retry, reconnect, or enter a new API key. Move the workflow to another supported feedback provider. This package does not migrate data, recover deleted data, route old keys to Qualtrics, send surveys, manage people, or create exports. No triggers or replacements are registered.

See the [official sunset FAQ](https://help.delighted.com/article/840-delighted-sunset-faq) and [current product notice](https://www.qualtrics.com/delighted/). Historical API documentation is retained only as context for existing tool contracts.
