# <img src="logo.png" height="20"> Appcircle

Automate mobile CI/CD for iOS and Android apps. Discover build profiles, commits, workflows, configurations, signing identities, and organizations. Start and cancel builds, inspect their status, manage build environment variables and testing groups, and share app versions with testers. Inspect store publish profiles and control publishing, manage Enterprise App Store app versions, and configure provider webhooks.

Authenticate with a Personal Access Key or organization API Key. Expiring access tokens are renewed by exchanging the configured credentials again. Custom authentication and API base URLs support self-hosted deployments.
