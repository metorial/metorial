# <img src="logo.png" height="20"> Byteforms

Read forms, surveys, and quizzes built on the ByteForms platform. List account forms, inspect their field definitions and configuration, and retrieve form submissions with cursor-based pagination, ordering, and search filtering.

Connect with an API key from the ByteForms account page. Call `list_forms` to discover a form ID before using `get_form` or `list_form_submissions`.

The [official API reference](https://forms.bytesuite.io/docs/api) documents these three read endpoints. This integration does not expose form editing, file export, or third-party delivery operations.
