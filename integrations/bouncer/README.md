# <img src="logo.png" height="20"> Bouncer

Verify and validate email addresses for deliverability, toxicity, and domain health. Perform real-time single email verification, synchronously verify up to 10,000 emails, or asynchronously verify up to 100,000 emails per batch. Check if emails are deliverable, undeliverable, risky, or unknown, and detect disposable, role-based, or catch-all addresses. Run toxicity checks on a 0-5 scale. Download verification and toxicity results as JSON, finish a running batch early, and delete stored batch or toxicity data. Verify domain MX records and catch-all behavior. Monitor account credit balance for usage tracking.

See the [Bouncer API documentation](https://docs.usebouncer.com/quick-start) for API key setup and supported operations.
