# Grist

Manage organizations, workspaces, documents, tables, columns, and records in Grist's relational spreadsheet-database. Discover the connected user and authorized organizations, rename workspaces, and restore trashed workspaces or documents. Create tables and modify columns with typed fields. Fetch, add, update, delete, and upsert records with filtering and sorting. Execute read-only SQL queries and receive records with their field values. Create and manage webhooks for row-added and row-updated events. List and download attachments, or download documents as SQLite files. API-key connections support hosted and self-hosted Grist servers.
