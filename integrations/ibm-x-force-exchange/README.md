# IBM X-Force Exchange

Look up threat intelligence for IP addresses, URLs, malware, and vulnerabilities. Retrieve reputation history and malware samples, search vulnerabilities by CVE, XFID, Microsoft bulletin, or keywords, and perform DNS and WHOIS lookups. List and search private or public threat intelligence collections, retrieve collection details, and access the existing collection creation action. Browse analyst-curated threat reports and internet application risk profiles, retrieve your user profile, and monitor API usage and entitlements.

API access requires an eligible IBM X-Force subscription. Premier reports require the relevant report entitlement. See the [official API documentation](https://api.xforce.ibmcloud.com/doc/) for current access requirements.
