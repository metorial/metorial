# <img src="logo.svg" height="20"> Renderform

Generate images, PDFs, and asynchronous videos from templates; capture websites as images or PDFs. Discover and manage templates, edit HTML template content, inspect or delete render results, and check the connected organization's credit usage and plan.

Completed generated files are retrieved from RenderForm's CDN and prepared for download. Pending video renders can be checked with `get_result`. File preparation can fail independently of a successful render, and later download availability requires verification. RenderForm removes generated files from free accounts after 14 days; retrieving a result does not renew that retention period.
