# <img src="logo.png" height="20"> Beeminder

Track and manage commitment-based goals with financial accountability. Create and update goals; list active and archived goals of various types (Do More, Do Less, Weight Loss, Odometer, etc.). Add, update, and delete datapoints on goals with idempotent upsert support. Manage the Bright Red Line commitment trajectory, adjust pledge levels, ratchet safety buffers, and trigger instant derails. Retrieve user profile information and poll for goal updates efficiently. Create monetary charges against users. Queue graph and autodata refreshes. Read user changes with incremental filtering and preserve provider response details. Batch datapoint submissions expose successes and errors separately.
