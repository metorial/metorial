# <img src="logo.png" height="20"> Screenshot.fyi

Capture website screenshots with full-page capture, custom viewport sizes, dark mode, cookie banner removal, and PNG or JPEG output. Each capture uses your account's screenshot allowance. The tool returns the provider's screenshot URL and prepares the generated image for download when the documented file host is available.

Save the image promptly: the provider does not document an exact URL lifetime or a retrieval-only renewal endpoint. If image retrieval or download preparation fails during the call after capture succeeds, the result includes a warning and the provider URL. Later file delivery can fail separately. Repeating the capture may use additional allowance.
