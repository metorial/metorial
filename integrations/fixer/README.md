# <img src="logo.png" height="20"> Fixer

Retrieve real-time and historical foreign exchange rate data for 170+ world currencies. Convert amounts between currencies, query historical rates back to 1999, fetch time-series data for date ranges up to 365 days, and get fluctuation data showing changes across a requested period. List all supported currencies including Bitcoin, Gold, and Silver.

## Authentication

Choose `apilayer` (the default) for an APILayer Marketplace API key, or `fixer` for a fixer.io account access key. Existing connections without a host selection continue to use APILayer. Both hosts use HTTPS; keys and subscription entitlements belong to the selected host. Endpoint availability and supported base currencies depend on that subscription.
