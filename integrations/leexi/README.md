# Leexi

Transcribe, analyze, and summarize calls and meetings using AI. List users and teams in a workspace. Retrieve call transcripts, summaries, and AI-generated content such as chaptering and topics. Create calls by uploading recordings via presigned URLs. Manage meeting events with scheduling, participants, and recording preferences. Launch the AI meeting assistant to join active conferences.

List and retrieve call notes, including their translations, and update a note's translated text for an existing locale. Recording upload requests return the URL, recording key, and required PUT headers. Call details include word-level transcripts and AI-detected topics.

API keys use Basic authentication and must have the permission scopes required by the selected tools. Calls and call notes are restricted to the key's configured access scope. See the [official API reference](https://docs.public-api.leexi.ai/reference/public-api) and the [capability guide](docs/SPEC.md).
