# Super G̴͎̬̼̾̈́̍͠o̶͇͓̅̐̿o̷͍̓̓̄̚g̶͎̩̾̏l̸̛̬̓e̸̗̮͘ 3

Work across Google Cloud infrastructure, analytics, storage, functions, speech, vision, address validation, and Firebase through one Google OAuth connection.

The 115 tools include `get_current_user`, which retrieves the connected Google account without requiring project configuration. OAuth requests only `cloud-platform`, `firebase.database`, `userinfo.email`, and `userinfo.profile`. Supported narrower permissions remain accepted by the relevant tools for existing connections. Existing grants are unchanged until you reconnect.
