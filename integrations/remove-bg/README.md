# Remove.bg

Remove image backgrounds automatically using AI. Detect foreground subjects (people, products, animals, cars) and remove or replace backgrounds with solid colors or custom images. Configure output size, format, cropping, scaling, positioning, and shadow effects. Define regions of interest for selective background removal. Download processed files in PNG, JPG, WebP, or ZIP format. Retrieve foreground position metadata and account credit balance information. Submit feedback to improve result quality.

See [API capabilities and compatibility notes](docs/SPEC.md). The provider announces a move to Leonardo.Ai starting December 1, 2026; review the [official API page](https://www.remove.bg/api) for migration guidance.
