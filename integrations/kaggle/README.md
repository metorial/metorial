# Kaggle

Search Kaggle competitions, datasets, notebooks, and models. Inspect competition files, leaderboards, and submission history; inspect dataset metadata and files; retrieve notebook source, output metadata, and execution status; create dataset versions, push notebooks, and manage models and variations. Download dataset and competition archives or individual files, and download a specific model variation version.

Connect with your Kaggle username and the legacy API key from `kaggle.json`. Create these credentials under **Legacy API Credentials** at [Kaggle API settings](https://www.kaggle.com/settings/api). Personal API tokens and OAuth tokens are different credentials and cannot be used with this connection method.

Dataset creation and model version creation require existing Kaggle upload tokens. File upload initialization, competition prediction submission, notebook deletion, and CLI-local configuration are not exposed.
