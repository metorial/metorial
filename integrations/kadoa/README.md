# <img src="logo.svg" height="20"> Kadoa

Create and manage extraction workflows using natural-language instructions, retrieve structured records, and inspect run history. Pause, resume, schedule, or update existing workflows, including custom cron schedules and record limits. Start website crawls, monitor their progress, and retrieve individual page content as a downloadable file. Run ad-hoc extractions, discover supported scraping countries, and inspect detected data changes.

The integration uses your workspace API key from Kadoa Settings > General.

Tools: `list_workflows`, `create_workflow`, `get_workflow_details`, `get_workflow_data`, `run_workflow`, `manage_workflow`, `start_crawl`, `get_crawl_results`, `adhoc_extraction`, `get_data_changes`, and `list_locations`.
