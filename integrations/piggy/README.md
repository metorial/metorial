# <img src="logo.png" height="20"> Piggy

Manage Piggy (Leat) loyalty contacts, identifiers, rewards, promotions, vouchers, gift cards, prepaid balances, and automations. Discover shops and contact attributes, preview loyalty credits, browse transaction history, and reverse credit, prepaid, or gift card transactions.

Connect with a Personal Access Token from a Private App in the business dashboard. Existing client-credentials OAuth connections remain supported. A default shop is optional; use `list_shops` to discover shops and provide a shop UUID with operations that need one.

See [API coverage and usage](docs/SPEC.md) for available operations and provider constraints.
