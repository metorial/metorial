# <img src="logo.svg" height="20"> Simple Analytics

Retrieve privacy-focused website statistics and event counts with date ranges, page filters, and exact metadata filters. Export raw page views and events as records or downloadable CSV and JSON files, including custom metadata. List tracked websites and add sites with a timezone, visibility, and label.

The API key is required for private statistics. Raw exports and website management also require the User ID from your account settings. Adding a website can automatically upgrade the account to a Business or Enterprise plan.

See the official [Stats API](https://docs.simpleanalytics.com/api/stats), [Export API](https://docs.simpleanalytics.com/api/export-data-points), and [Admin API](https://docs.simpleanalytics.com/api/admin) documentation.
