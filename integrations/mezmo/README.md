# <img src="logo.png" height="20"> Mezmo

Use Mezmo Log Analysis to ingest and search logs, download filtered JSONL exports, manage views, preset alerts, boards and exclusion rules, inspect usage, and configure account-wide ingestion and archiving.

Connect with an IAM access token from your organization API key settings. Log ingestion additionally requires a separate ingestion key. Account usage reports bytes; application, host and tag reports retain percentage units by default and support `metric="bytes"`.

Alert channels can notify external recipients. Active exclusions can discard logs, and ingestion and archiving controls affect the whole account. Use authorized test accounts when verifying these operations.

API reference: [Mezmo Log Analysis API](https://docs.mezmo.com/log-analysis-api). This integration does not expose telemetry pipeline or organization membership management.
