# <img src="logo.png" height="20"> Sms Alert

Send individual and bulk SMS messages via transactional and promotional routes. Schedule SMS for future delivery, modify or cancel scheduled messages. Generate and validate OTPs for mobile number verification. Manage contacts and contact groups for bulk campaigns. Create and manage reusable SMS templates and sender IDs. Track delivery status via pull reports or push callbacks. Create shortened URLs for SMS links. Check account credit balance and read the connected account profile. List tools expose page and limit controls; use group and contact IDs for direct operations or existing names and numbers for discovery. Campaign date and sender filters apply to the returned page; use delivery status for recipient details.
