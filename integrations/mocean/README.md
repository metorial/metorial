# Mocean

Send and receive SMS, WhatsApp, and voice messages globally across 190+ countries. Perform phone number verification (OTP/2FA) via SMS or Telegram. Look up mobile number details including carrier, porting status, and reachability. Make programmable voice calls with text-to-speech, DTMF input collection, and call recording. Manage WhatsApp message templates and send rich media, interactive messages, and template-based notifications. Query account balance and messaging pricing.

Report recipient-confirmed SMS delivery outcomes with `report_sms_conversion` to help improve delivery routing. WhatsApp template management supports both API tokens and API key/secret credentials.

API reference: [token authentication](https://moceanapi.com/docs) and [API key/secret authentication](https://moceanapi.com/docs/v2).
