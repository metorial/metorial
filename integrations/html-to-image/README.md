# <img src="https://provider-logos.metorial-cdn.com/html-to-image.png" height="20"> HTML to Image

Generate downloadable PNG, JPG, WebP, and PDF files from HTML/CSS, public webpages, or reusable templates. Browse generated images with cursor pagination, download existing images with optional resizing, manage templates and their versions, request image deletion, and inspect image usage history.

Connect with the API ID and API key from the [provider dashboard](https://htmlcsstoimage.com/dashboard). Keys need the permissions for the operations you use. Hosted images remain available while your account is active unless deleted. Downloading an existing image uses its permanent URL; it does not repeat image generation.

Use `request_image_deletion` for deletion requests. Its accepted status does not confirm completion. The deprecated `delete_images` tool retains its original result for compatibility.

See the [API guide](https://docs.htmlcsstoimage.com/getting-started/using-the-api/), [template guide](https://docs.htmlcsstoimage.com/getting-started/templates/), and [usage reference](https://docs.htmlcsstoimage.com/management-api/usage/).
