# <img src="logo.png" height="20"> Carbone

Generate documents by merging JSON data into templates (DOCX, XLSX, PPTX, ODT, ODS, HTML, XML, and more). Upload, download, list, update, and delete reusable document templates with Carbone tags. Render documents in various output formats including PDF, DOCX, XLSX, CSV, and XML. Convert between document formats using LibreOffice, OnlyOffice, or Chromium engines. Generate batch documents as ZIP or merged PDF files. Support asynchronous rendering with webhook notifications. Manage template versioning, metadata, categories, and tags. Synchronous renders include a downloadable document; use `download_document` for reports completed asynchronously. Generated reports expire after one hour and can be downloaded once; expired or consumed reports cannot be renewed.
