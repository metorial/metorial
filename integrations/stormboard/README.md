# Stormboard

Create and manage digital whiteboard Storms (workspaces). Create and read ideas (sticky notes), update sections and color legends, manage connectors and tags, send and read chat messages, and manage Storm participation. Duplicate, close, reopen, and favorite Storms, retrieve their templates, and read the connected user's profile.

Connect using an API key from your [Stormboard account](https://www.stormboard.com/users/account#api). API operations can require a particular subscription or permission level. The integration includes 14 tools; it does not include webhook triggers or profile-editing tools.

See the [capability and verification notes](./docs/SPEC.md) for documentation limits.
