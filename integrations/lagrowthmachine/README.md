# La Growth Machine

Manage sales outreach leads, audiences, and campaigns in La Growth Machine. Create or update leads, import prospects from LinkedIn, retrieve detailed campaign statistics, and change lead campaign statuses. Send LinkedIn messages through existing conversations, discover workspace members and connected identities, and manage inbox webhooks for sent and received LinkedIn and email messages.

API access requires an eligible plan and an API key from Settings > Integrations & API. LinkedIn imports run asynchronously, and messaging requires an existing conversation with the sending identity. A successful message request confirms queueing, not delivery.
