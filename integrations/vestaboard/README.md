# Vestaboard

Send and read messages on Vestaboard smart display devices. Compose messages as plain text or character code arrays with support for colored blocks and precise positioning. Format messages using VBML (Vestaboard Markup Language) with layout styling, templates, and absolute positioning. Configure persistent Cloud transition effects or per-message Local API animations. Choose output dimensions when formatting text for a Flagship, Note, or custom display. Manage subscriptions to send messages across multiple boards. Supports Flagship (6×22), Vestaboard Note (3×15), and Cloud Note Array layouts. Existing Subscription API connections remain supported; the provider recommends the Cloud API for new connections. Local requests require network access to each board.
