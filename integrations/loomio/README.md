# <img src="logo.svg" height="20"> Loomio

Create and manage group discussions, proposals, and polls for collaborative decision-making. Supports multiple voting methods including proposals, score voting, ranked choice, dot voting, and meeting polls. Create discussion threads with Markdown or HTML content and notify recipients. Configure poll options, anonymous voting, result visibility, and closing times. Manage group memberships by inviting users via email and syncing member lists. Discover your groups, retrieve discussions and polls, post comments, and edit discussion context. Page through group discussions and polls by status.
