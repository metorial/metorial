# <img src="logo.svg" height="20"> Kaleido

Manage enterprise blockchain networks through the Kaleido platform API. Discover organizations and consortia, manage environments, memberships, nodes, services, invitations, and application credentials, inspect runtime status and node logs, and retrieve audit history.

Contract projects group compiled Solidity versions. Create or discover a project with `manage_contract_project`, then use `manage_compiled_contract` to compile a GitHub file or import an ABI and bytecode. Promote a compiled version to a selected environment to make its Gateway API available.

Connect with a Kaleido administrative API key from **Profile Settings > API Keys** and select the deployment region. Application credentials generated by the tools are separate credentials for runtime access; save a newly created password immediately because it is shown only once.

API reference: [Kaleido platform API](https://api.kaleido.io/platform.html). Provisioning and deletion can complete asynchronously; retrieve the resource to inspect its state.
