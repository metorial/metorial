# <img src="logo.png" height="20"> Amcards

Send personalized physical greeting cards, schedule drip campaigns, and manage mailing contacts in AMcards. Discover configured Quicksend Templates and campaigns before sending, retrieve individual cards and contacts, and page through card history. Send requests support custom merge fields and return-address overrides.

Authenticate with an access token generated from your [AMcards account](https://amcards.com/user/generate-access-token/).
