# <img src="logo.png" height="20"> Boxhero

Manage BoxHero inventory items and stock transactions. Discover your token-linked team, locations, custom attributes, and supplier/customer partners. Create, look up, update, and delete items; record stock in/out, relative adjustments, and moves; retrieve full transaction details and apply revision-aware updates or deletions.

Items, locations, and stock operations require a team in Location mode. Transaction lists fetch details for each result; choose a smaller page limit for faster responses. See [the API specification](docs/SPEC.md) for stock sign rules, pagination, and partial-operation behavior.
