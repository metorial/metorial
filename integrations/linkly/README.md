# Linkly

Create and update branded short links, individually or in batches of up to 1000. Configure domains, slugs, UTM parameters, smart redirects, retargeting pixels, and expiry settings. Retrieve links, click analytics, and grouped traffic counts, or download analytics as CSV or TSV. Discover workspaces and domains, delete links, and manage click and link lifecycle webhooks.

Connect with an API key and workspace ID from Linkly Settings → API Keys. Requests use the current API host and Bearer authentication. Existing comma-separated analytics link filters remain supported alongside hyphen-separated IDs.

See the [API reference](https://linklyhq.com/url-shortener-api-reference), [link API guide](https://linklyhq.com/support/link-shortening-api), and [analytics guide](https://linklyhq.com/support/analytics-api).
