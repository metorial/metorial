# Countdown API

Search and retrieve real-time eBay product data across global eBay domains. Search product listings with filters for condition, sorting, and pagination. Retrieve detailed product information by eBay Product ID, GTIN, ISBN, UPC, or EAN. Fetch customer reviews and rating breakdowns for products. Look up seller profiles and seller feedback. Get autocomplete suggestions for eBay search terms. Create and populate bulk data collections of up to 15,000 requests, discover configured cloud storage destinations, and download completed results as JSON, JSON Lines, or CSV. Inspect collection settings and manage saved requests before starting a run. Identify the connected account, monitor usage and review error logs for failed requests.
