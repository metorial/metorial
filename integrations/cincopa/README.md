# <img src="logo.svg" height="20"> Cincopa

Manage media assets, galleries, portal settings, and live streams. Search and tag a media library, update gallery or asset metadata, import media from a URL, track or abort imports, and prepare gallery ZIP downloads. Retrieve the authenticated user and account permissions.

See [supported workflows and compatibility notes](docs/SPEC.md). API tokens use the permissions selected in the Cincopa Account Dashboard.
