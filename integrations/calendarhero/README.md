# <img src="logo.png" height="20"> Calendar Hero

Schedule and manage meetings with automated booking for 1:1 and group meetings. List, create, and delete meeting types; query scheduled meetings by date range; and create meeting requests using email addresses or existing contact IDs. Manage request reminders and cancellation, create and update contacts, search contacts by name or email, and retrieve contact insights and account-wide contact counts.

Connect with an API token from [CalendarHero API settings](https://app.calendarhero.com/settings/user#API). Meeting requests need a subject and at least one invitee. Date components define the availability range, while time components define the start and end of daily availability. Contact creation requires at least one email address; updates preserve existing email addresses when they are omitted.

See the [CalendarHero API reference](https://api.calendarhero.com/documentation) for endpoint details.
