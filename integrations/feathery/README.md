# Feathery

Create, manage, and collect submissions for forms and data intake workflows. Build forms from templates, track user submissions, and export them as PDFs. Inspect AI document extraction runs. Fill and sign document templates (PDF, DOCX, XLSX) with field values and route them for e-signatures. Manage users and their form session progress. Create white-label workspaces with custom branding and feature limits. Inspect the authorized team and invite members with role-based permissions. Delete generated document envelopes. Access logs for API errors, emails, and integrations.
