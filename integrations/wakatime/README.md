# <img src="logo.svg" height="20"> Waka Time

Read WakaTime coding summaries, statistics, durations, heartbeats, projects, and commit details. Record heartbeats and external activities such as meetings or code reviews, and read the resulting external durations. View goals, organizations, dashboards, machines, insights, and public or private leaderboards. Request coding data exports and download completed results.

Use OAuth for activity reads and external durations. API keys are write-only and support sending heartbeats.
