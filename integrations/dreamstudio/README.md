# DreamStudio

Generate images from text prompts using Stable Image Ultra, Core, and Stable Diffusion 3.5. Edit, relight, upscale, and guide images with sketch, structure, or style references. Download generated image files and GLB 3D models, recover asynchronous results, and check account identity and credit balance.

Hosted video generation was retired by Stability AI on July 24, 2025. Legacy file tools remain available for compatibility and direct callers to the downloadable-file tools.
