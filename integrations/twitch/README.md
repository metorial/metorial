# Twitch

Connect a Twitch user through OAuth or provide a user/app access token and its exact registered Client ID. Tokens are validated against Twitch before each invocation. App tokens have no human profile and are accepted only by native endpoints and delegated grants that support them. User actions require the correct authorized broadcaster/moderator and scopes; reconnect when a stored token lacks a required scope. The legacy optional broadcaster configuration does not replace explicit tool inputs.

19 tools cover current-user/user lookup, channel lookup/update, stream discovery, chat messages/announcements, bans/timeouts/message deletion/Shield Mode, followers/subscriptions, clip creation/discovery/download, videos, polls/predictions, custom rewards/redemptions, chat settings, raids, roles, commercials, shoutouts and search. Lists return native cursors; use them to retrieve subsequent pages. Empty permission-limited follower results do not establish that a user does not follow.

Clip downloads select an exact broadcaster, clip and landscape/portrait rendition, require the native editor/broadcaster grant, and produce an MP4 up to 64 MiB. Temporary URLs are consumed immediately; Twitch does not publish an expiry timestamp for these URLs. Creation of clips and raids is asynchronous acceptance. Chat may be dropped: inspect sent and dropReason. Poll choices and prediction outcomes include IDs needed to end or resolve them.

Affiliate/partner, live-broadcast, moderator, editor, application ownership and cooldown requirements apply per Twitch endpoint. Deleting a reward marks outstanding UNFULFILLED redemptions as FULFILLED; do not assume cancellation or refunds. Canceled and fulfilled redemption history is available only for a few days, so an empty history does not prove lifetime disuse. Chat, clips, poll/prediction history and raid/publication effects may remain. Channel updates return accepted/confirmed flags; updated is true only when a native readback matches the requested state. Reconcile uncertain writes before retrying. No EventSub registration or background monitoring is included.

Documentation: [Helix reference](https://dev.twitch.tv/docs/api/reference/), [OAuth](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/), [token validation](https://dev.twitch.tv/docs/authentication/validate-tokens/), [refresh](https://dev.twitch.tv/docs/authentication/refresh-tokens/).
