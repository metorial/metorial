# <img src="logo.jpg" height="20"> Blackboard

Manage Blackboard Learn courses, users, enrollments, course content, grade columns, student grades and assignment attempts. Create course announcements, manage course groups and membership, track attendance, and list or create calendar events. Discover academic terms, calendars, and data sources, and inspect the current connection user.

The connection uses the institution’s Learn instance URL and either user-authorized OAuth or client credentials. Available operations depend on the connected user’s Learn entitlements. Course content tools manage text, folders, and external links; they do not upload files or create assignments.
