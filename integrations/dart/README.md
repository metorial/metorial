# Dart

Create, read, update, and delete tasks with properties like status, priority (P0–P3), assignees, due dates, tags, and custom fields. Manage task relationships including blockers, subtasks, and duplicates. Add comments to tasks. Create, retrieve, update, search, and delete documents for wikis, meeting notes, and project descriptions. Retrieve workspace configuration including available dartboards, folders, statuses, tags, assignees, and priorities. Check the connected account identity. Record time spent on tasks, optionally for another user or a custom time tracking property. List tasks, comments, and documents with pagination metadata.
