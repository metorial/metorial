# Ecologi

Fund climate and nature projects through Ecologi: global or country-specific tree planting, carbon avoidance, permanent carbon removal, and habitat restoration. Read public impact totals by username, including pending amounts. Purchasing tools support test mode, recipient notifications, and idempotency keys for safe retries.

Purchases require an API key from **Integrations → API keys** in your Ecologi account. Public reporting works without authentication. See the [Ecologi API reference](https://docs.ecologi.com/) for current pricing and billing terms.
