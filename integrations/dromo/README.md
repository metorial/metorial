# Dromo

Manage Dromo import schemas, upload metadata, and headless imports with a backend API key. List uploads and headless imports with pagination, create and update saved schemas with validators and serialized hooks, start imports from a file or JSON records, and download processed JSON results. Headless imports require Dromo's premium Headless add-on.
