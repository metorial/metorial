# Coassemble

Create, manage, and deliver e-learning courses programmatically. List, retrieve, duplicate, delete, and restore courses, and read their text, translation variants, and media catalog. Generate courses using AI by providing prompts, audience, tone, and screen count. Embed course player and course builder into third-party applications via signed URLs. Publish and revert course versions. Prepare downloadable SCORM 1.2 or 2004 packages. List and retrieve clients and users, update their metadata, and manage their lifecycle. Track learner progress by course, user, client, and date range.

Use **Workspace API Key** with the full `COASSEMBLE:<workspaceId>:<secret>` key from your workspace API settings. The older user ID/API key method remains available for existing credentials; the bearer method is retained for existing connections.

Endpoint availability depends on your workspace's API access. SCORM export requires partner access. AI generation defaults to a general audience, beginner familiarity, a professional tone, and six screens when those optional inputs are omitted.
