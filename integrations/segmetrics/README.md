# <img src="logo.png" height="20"> Segmetrics

Import and retrieve marketing attribution and analytics data. Create, update, and delete contacts with UTM parameters, tags, and custom fields. Manage orders/invoices with line items and refund status. Create and manage subscriptions with billing cycle configuration. Track ad performance including spend, clicks, and impressions across campaigns, ad sets, and ads. Retrieve saved reports for leads, revenue, ads, and subscriptions with KPIs, time series graphs, and tabular breakdowns. Run ad hoc Data Explorer queries with dimensions, metrics, filters, and comparisons. Access full customer journey data including page views, tags, orders, and attribution touchpoints. Identify website visitors and link them to CRM contacts.

## Connection and imports

Connect with the Account ID and API key from the gear menu → Account Settings. Import tools accept `integrationId`: open the gear menu → Integrations → the integration menu → Configure Integration, then use the last number in the URL. Existing connections retain their stored account and integration context.

For `run_report_query`, copy the report JSON from the report-actions menu → Access from API. The result preserves the full report response.
