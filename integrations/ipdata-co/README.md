# <img src="logo.png" height="20"> Ipdata.co

Look up geolocation, threat intelligence, and ownership data for any IP address. Retrieve geographic details (continent, country, region, city, postal code, coordinates), detect threats (Tor, proxy, known attackers, spammers, bogons), and identify the owning company or organization. Supports single and bulk IP lookups (up to 100 IPs), ASN data queries, mobile carrier detection, timezone detection, currency and language detection, and response field filtering. Provides an EU-specific endpoint for data residency compliance. Read API usage, inspect blocklist matches and plan-eligible VPN/reputation scores, and retrieve advanced ASN assignment and network relationship data. Bulk and advanced ASN lookups require a paid API key. Omitting an IP address looks up the server making the request.
