# <img src="logo.svg" height="20"> Winston AI

Detect AI-generated text and images, check for plagiarism, verify factual claims, and compare texts for similarity. Submit text as plain content, a file URL, or a website URL. Submit images by public URL or base64 data. AI text detection returns human scores (0–100), per-sentence scores, readability analysis, and obfuscation attack detection. Image detection provides probabilities (0–1), C2PA provenance, EXIF metadata, and watermark detection. Advanced image forensics adds a classification, authenticity assessment, and explanations from individual forensic methods. Plagiarism scans return matched sources and text positions; fact checks return claim verdicts and references; text comparisons return similarity scores and match positions.

API tokens come from the [Winston AI Developer Dashboard](https://dev.gowinston.ai). The API account is separate from the consumer web app. See the [official API documentation](https://docs.gowinston.ai/api-reference/introduction) for supported languages, model versions, and credit costs.
