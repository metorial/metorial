# DeployHQ

Manage DeployHQ projects, servers, config files, and SSH commands. Discover available deployment zones and your authenticated user profile. Queue, preview, or schedule deployments; inspect paginated deployment history; retry, roll back, or abort a deployment; and cancel deployment schedules. Update project notifications, server connection settings, and deployment commands.
