# <img src="logo.png" height="20"> DocuPost

Send letters from a PDF URL or HTML, send postcards from front/back images, and request account balance information. Sending physical mail can incur charges. An API response does not establish successful printing or delivery; inspect the DocuPost dashboard after submission and before retrying an uncertain request.

Authenticate with an API token from the Developer page. The existing balance endpoint remains available for compatibility, although it is not described in the current public API guide. Manage funding, mail tracking, cancellation, addresses, and exports in the dashboard.

See the [API guide](https://help.docupost.com/developer-documentation/send-letter-api) and [integration reference](docs/SPEC.md) for supported inputs and limitations.
