# Truvera

Issue, verify, manage, and revoke W3C-compliant verifiable credentials using decentralized identifiers (DIDs). Create and manage DIDs, define and retrieve credential schemas, build verification proof templates, list and inspect proof requests, and manage revocation registries. Discover the authenticated user profile, manage organization branding, and track asynchronous operations with job status checks.

Connect with a Truvera API key and select the matching production or test environment. Credential listing supports search and exact holder-DID filtering. On-chain mutations return a job ID; use `get_job` to confirm completion before relying on the result.
