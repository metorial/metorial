# <img src="logo.png" height="20"> Bolt IoT

Control and monitor IoT devices connected via Bolt WiFi modules. Set and read digital GPIO pin states to control LEDs, relays, and motors. Read analog sensor values (e.g., temperature, light) and write PWM output for variable device control. Manage UART serial communication to send and receive data with external microcontrollers like Arduino. List devices, check online/offline status, query firmware versions, and restart devices remotely. Device tools accept an optional Device ID override, and return complete provider responses alongside their existing results. Read the cloud-reported online status and status-change time, or query hardware and firmware versions directly.
