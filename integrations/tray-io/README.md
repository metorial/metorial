# Tray

Discover connector operations and service environments, manage Embedded end users and their solution instances, and import service authentications. The integration provides 19 tools and no event subscriptions.

Connect using a master or user bearer token and its US, EU or APAC region. Embedded APIs require the corresponding account entitlement. Master tokens manage external users and read solution templates; user tokens create, update, remove and upgrade their own solution instances and call connectors. Authentication metadata supports documented user or master access. User tokens authorized by a master token expire after two days; reconnect with a newly authorized token. There is no automatic refresh.

The saved credential owns its region. Older connections can use a saved region setting, including when reconnecting without a new region, defaulting to US if neither is present. Conflicting settings are refused before connecting or making a request. Get Current Context validates an authorized read and reports configured mode and region; it does not claim a human identity. Use List Users, List Solutions, List Solution Instances and List Authentications to discover native IDs. GraphQL lists return one page with an opaque `pageInfo.endCursor`; pass it unchanged as `after` while `hasNextPage` is true.

Get Resource reads exact external-user, solution or authentication metadata. Get Connector Operations can discover a connector's native service mapping and service environments. Authentication credentials are not returned. Call Connector requires a user token and is billable; the operation may change third-party resources. Enabling or upgrading an instance can execute workflows. Removal does not reverse executions, external changes, charges or audit history.

Writes are not automatically retried. Instance creation verifies each supplied configuration and authentication slot assignment while preserving native template defaults and other slots. Creation receipts preserve native IDs when exact readback fails; inspect those IDs or the unique external-user marker before retrying an uncertain operation. Successful removal requires an independent absence read. Complete discovery is bounded, and incomplete or stalled pagination is refused.
