# Codemagic

Manage CI/CD pipelines for mobile applications. Add and list applications, trigger and cancel builds, retrieve build status, and download build artifacts. Manage build caches, discover application variable groups, and add environment variables and secrets. Retrieve the authenticated user and resource permissions. Supports Flutter, React Native, native iOS/Android, Unity, and other mobile frameworks. Configure builds with custom environment variables, software version overrides, labels, and machine types.
