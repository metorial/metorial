# <img src="logo.svg" height="20"> Parallel

Perform AI-optimized web searches, extract content from URLs, run deep multi-step research tasks, and discover entities matching natural language criteria. Provides web-grounded chat completions compatible with OpenAI client libraries. Supports structured JSON output schemas, multiple processing tiers for cost/thoroughness trade-offs, and asynchronous task execution with polling or webhook-based completion tracking.

Inspect FindAll run criteria and enrichments, request additional matches, or stop a run while keeping previously discovered candidates. Retrieve partial candidate snapshots and the original structured enrichment values. Monitor tools support the documented Alpha API contract, including existing monitor IDs and event dates.
