# <img src="logo.png" height="20"> Gorgias

Manage support tickets, customer profiles, ticket tags, reusable macros, and automation rules in Gorgias. Create customer and agent messages, add internal notes and file URLs, merge customer records, and list satisfaction surveys. Discover the current user, helpdesk teams, and saved ticket views for assignment and queue filtering.
