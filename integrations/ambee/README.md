# <img src="logo.png" height="20"> Ambee

Retrieve environmental data with 20 read-only tools. `query_environment` accesses current air quality, pollen, and weather APIs by coordinates or place, including latest data, hourly history, 48-hour forecasts, and 120-hour pollen or weather forecasts. Select an AQI standard, request local timestamps, or include pollen species risk where available.

`query_disasters` lists processed natural disaster events by location, country, or continent and retrieves affected geometry using an event ID. Additional tools cover geocoding, wildfire risk, and legacy environmental datasets. Access and geographic coverage depend on your Ambee subscription. Connect using an API key from the Ambee API Dashboard; weather units and response language are configurable.
