# <img src="logo.png" height="20"> Bugherd

Track bugs and manage visual website feedback. Create, update, and organize tasks on Kanban-style project boards with custom columns. Manage projects linked to website URLs, add team members and guest clients, and configure project settings. Create and filter tasks by status, priority, tags, assignee, and date ranges. Add comments to tasks (public or private), add and manage file attachments by URL, and move tasks between projects. Find tasks by their project-scoped number. Page through project and user lists. List users, view their assigned tasks across projects, and read organization details.
