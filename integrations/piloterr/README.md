# <img src="logo.svg" height="20"> Piloterr

Extract website HTML, technology and contact information; retrieve public LinkedIn, Instagram, GitHub and Trustpilot data; search Google, Bing, Brave and Amazon; inspect Amazon, Shopify and Walmart products; enrich companies and Crunchbase funding data; verify emails and domain reputation; prepare webpage screenshots for download; and inspect account credit usage.

The integration uses the current [Piloterr API](https://docs.piloterr.com/introduction). Read-only extraction calls can consume credits. `check_usage` is free and includes current account identity and key status when returned. `capture_screenshot` prepares downloadable PNG, JPEG, WebP, or PDF files; `screenshot_webpage` remains available for existing callers and is deprecated. The API catalog contains additional endpoints beyond the capabilities registered here.
