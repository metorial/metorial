# Recall.ai

Schedule and manage meeting bots, read their status and completed transcripts, and download mixed video, mixed audio, or transcript files. Discover connected Google Calendar and Microsoft Outlook calendars, read their events, schedule a bot with a stable deduplication key, and cancel an upcoming event's bot. Bots in an active controlled meeting can send chat messages, play MP3 audio when configured before dispatch, or stream a webpage through their camera or screenshare.

Use the API key and region from your Recall.ai workspace. Bot and recording calls use API V1; connected-calendar workflows use Calendar V2. Schedule production bots at least ten minutes ahead of the meeting. Current workspaces expose completed recording media through recording IDs; legacy transcript responses remain supported when the workspace returns the older bot shape.
