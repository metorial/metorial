# <img src="logo.png" height="20"> Habitica

Manage Habitica Habits, Dailies, To-Dos, and Rewards: create, retrieve, update, delete, and score tasks; manage checklist items; organize tasks with tags; and inspect your character profile and stats. Cast class skills, manage equipment and pets, send messages, manage available groups and challenges, and participate in quests. Retrieve game-content summaries and spell identifiers.

Authenticate with your Habitica User ID and API Token from Settings > Site Data (or Settings > API on mobile). The required application identifier belongs to the API Credentials connection and must use Habitica's `CreatorUserID-AppName` format with the tool creator's Habitica User ID. Existing connections keep using their saved application identifier until reconnected.

Habitica has retired public guild and Tavern features, and some legacy private group operations require special access or an active group plan. Availability and permissions are enforced by Habitica. Challenge listing uses zero-based pages of up to ten results. The integration does not expose webhook registration tools.
