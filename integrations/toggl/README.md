# <img src="logo.svg" height="20"> Toggl

Track time spent on tasks and projects with Toggl Track. Create, inspect, update, stop, and delete time entries. Manage projects, clients, tags, and tasks, and retrieve projects or clients by ID. Discover available workspaces with `get_workspace` and inspect the authenticated account with `get_me`. Workspace operations use the account's default workspace unless a workspace ID is provided. Summary and detailed reports support date ranges and project, client, tag, user, and billable filters; detailed reports return pagination cursors for subsequent pages. Tasks and some billing or reporting features require an eligible plan.

Authentication uses the Toggl Track API token from your profile. No workspace ID is required at connection setup. Existing connections retain their saved workspace default when available.
