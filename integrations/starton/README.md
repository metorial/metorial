# <img src="logo.jpeg" height="20"> Starton

Deploy and interact with smart contracts on EVM-compatible blockchains. Deploy from contract templates (ERC20, ERC721, ERC1155) or custom bytecode, import existing contracts, discover their functions, and call read or write operations. Track submitted transactions by ID and upload JSON metadata to IPFS. Create, pause, resume, and manage blockchain watchers that send webhook notifications. Discover supported networks and key management systems, create or list managed wallets, and retrieve native currency balances.
