# <img src="logo.png" height="20"> OpenCage

Convert addresses and place names to coordinates, or coordinates to addresses, using OpenCage's worldwide geocoding API. Narrow forward results by country, bounding box, or proximity, and retrieve location annotations such as timezone, currency, road information, and alternative coordinate formats. Batch geocode up to ten location queries with one API request per query. Results include subdivision codes and, for reverse queries, distance from the requested coordinates when available.
