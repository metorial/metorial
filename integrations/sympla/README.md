# <img src="logo.png" height="20"> Sympla

Read event, order, participant, and affiliate data from Sympla, and check participants in by ticket ID or ticket number. Discover current API event ID hashes, browse scheduled presentations with cursor pagination, and retrieve presentation details including dates and sectors. Existing event, order, participant, and affiliate tools retain their legacy numeric-ID API contracts. Event creation and editing are not exposed by the documented public API.
