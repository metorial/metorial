# Best Buy

Search Best Buy's product catalog for consumer electronics with pricing, specifications, descriptions, and images. Browse product categories, find store locations with hours and services, and check in-store product availability by store or postal code. Retrieve product recommendations including trending, most viewed, also viewed, and also bought products. Access open box deals with condition ratings and discounted pricing. Cursor browsing supports large product, store, and category result sets. Open Box category queries support page and page-size controls.

Connect with a Best Buy Developer API key. This integration covers the public read-only APIs. Best Buy's separate, invite-only Commerce API is outside its scope.
