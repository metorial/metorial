# Whoisfreaks

Look up live and historical WHOIS data for domains, IPs, and ASNs. Query live, historical, and reverse DNS, discover subdomains, check domain availability, and retrieve SSL certificates. Search WHOIS records by keyword, owner, email, or company. Retrieve IP geolocation, IP and domain reputation, and API subscription and credit usage. Supports bulk WHOIS, DNS, availability, and geolocation queries.
