# <img src="logo.png" height="20"> Fomo

Manage social proof notifications that display real-time customer activity (purchases, signups, reviews) on websites. Create, retrieve, search, update, and delete notification events with customer names, locations, and custom attributes. Create notification templates using variable placeholders. Retrieve application statistics and control notification timing, age limits, timestamp thresholds, mobile visibility, looping, position, theme, and UTM tracking. Access Fomo's public marketing metrics including signup counts, customer counts, and integrations.

Connect with the API token for your website from **Settings > Site**. API access normally requires a paid Fomo plan; contact Fomo if you need API access for testing. Existing template IDs and tags are available in the Fomo Templates screen.
