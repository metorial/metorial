# <img src="logo.png" height="20"> Beaconcha.in

Query Ethereum consensus and execution data on mainnet or Hoodi. Inspect network state, epochs, blocks, slots, validator performance, rewards, balances, duties, and staking queue estimates. Manage validators in existing dashboards, compare staking entities, retrieve gas fee recommendations and address token balances, and read previously submitted machine monitoring metrics.

Connect with a Beaconcha.in API key from [API key management](https://beaconcha.in/user/api-key-management). API access and request limits depend on your subscription. Dashboard mutations require Orca; entity comparisons require Scale or Enterprise. Dashboards and groups are created in the provider web interface.

Paginated results include provider cursors. Pass the corresponding cursor back with the same filters to continue. Validator overview and balance lists have separate cursors; slot duty, deposit, and withdrawal lists also have separate cursors.

[API documentation](https://docs.beaconcha.in/api/overview)
