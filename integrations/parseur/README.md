# <img src="logo.jpeg" height="20"> Parseur

Extract structured data from emails, PDFs, and other documents using AI-powered parsing. Submit email content or upload file bytes, create and copy mailboxes, and retrieve parsed data and processing logs. Inspect, copy, or delete existing templates, configure webhooks, and access mailbox schemas. Uploads and mailbox copies are asynchronous; list the resources afterward to check their status.
