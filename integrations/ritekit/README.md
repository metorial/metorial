# <img src="logo.svg" height="20"> Ritekit

Analyze and suggest hashtags for social media posts based on real-time popularity and trending data. Detect banned Instagram hashtags. Generate styled quote images and animated GIFs from text or static images. Extract company logos, brand colors, and resolve company names to domains. Run focused email checks or retrieve full insights to enrich email addresses by detecting freemails, disposable emails, typos, and extracting names. Suggest and auto-insert emojis into text. Shorten links with optional call-to-action overlays. Extract article content, top images, and link previews from URLs.

Connect with a Client ID from the [RiteKit API Console](https://ritekit.com/developer/dashboard/). OAuth is not supported. Use `check_email` for one targeted free-provider, disposable-provider, spelling, or name check. These checks do not verify mailbox existence.

Quote images support optional dimensions and font weights. Company logos support square sizing, background treatment, and fallback generation. Generated images and logos include a downloadable copy when available, while retaining the actual provider URL and reporting any download failure separately.

See the [API specification](docs/SPEC.md) for capability coverage and provider limitations.
