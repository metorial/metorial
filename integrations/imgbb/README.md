# ImgBB

Upload images to ImgBB from base64-encoded data or an image URL and receive a downloadable image with publicly accessible hosted URLs. Set optional auto-expiration times for temporary hosting. Returns original and thumbnail URLs, a medium-sized URL when available, and viewer, display, and delete URLs. Keep the delete URL secure because it allows manual image removal.
