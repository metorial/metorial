# Claid.ai

Enhance, edit, and generate images using AI-powered processing. Upscale and restore photos, remove or replace backgrounds, resize and reformat images, blur license plates for privacy, and apply style transfers. Generate product backgrounds from text prompts or templates, create AI fashion model photoshoots from garment photos, generate images from text descriptions, and convert static images to video animations. Edit images with natural-language instructions, retrieve asynchronous results, and discover and manage cloud storage connectors for input/output.
