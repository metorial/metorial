# <img src="logo.svg" height="20"> Radar

Track user locations and manage geofences, trips, and location events. Create circle, polygon, or isochrone geofences; list and inspect users; create, update, list, inspect, and delete trips; perform forward, reverse, and IP geocoding; search nearby places and geofences; calculate routing distances, directions, and distance matrices; and validate postal addresses. Address validation is available for US and Canada addresses for enterprise customers. Authenticate with a Radar secret API key; the key determines the test or live environment.
