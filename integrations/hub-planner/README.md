# Hub Planner

Manage resource scheduling, project planning, bookings, and timesheets. Create, retrieve, update, delete, and search projects and resources. Schedule bookings with percentage or minute-based allocation, retrieve booking categories, and track actual time through timesheet entries. Discover clients and schedulable events, and manage events, project milestones, vacations, and public holidays. Search and list tools support pagination where documented.

Use a generated API key from Settings > API. Mutations require a read/write key. Timesheets and vacations require their corresponding account extensions; custom booking category groups require the Booking Category Groups extension.
