# Wisepops

Export contacts and leads collected through website popup campaigns, including emails, phone numbers, and custom form fields. Retrieve campaign reporting metrics such as display counts, click counts, and email counts. Manage webhooks for real-time notifications on email, phone, and survey form submissions. Delete and suppress end-user data for GDPR/CCPA compliance.

Download a contact batch as a JSON file with `export_contacts`. Filter by collection date or campaign, with up to 1,000 contacts per request. The API documents no cursor or offset, so exports contain one batch rather than a guaranteed complete history. API access requires a Custom plan.

[API documentation](https://support.wisepops.com/en/articles/9897479-wisepops-api-documentation) · [Webhook documentation](https://support.wisepops.com/en/articles/9897509-webhooks)
