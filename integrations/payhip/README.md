# <img src="logo.jpeg" height="20"> Payhip

Manage coupons and software license keys for a Payhip e-commerce store. Create, list, and retrieve discount coupons with configurable options like percentage or fixed-amount discounts, usage limits, and date ranges. Verify, enable, disable, and track usage of software license keys tied to digital products.

Coupon tools use your account API key. License tools also require the matching product secret key. See the [integration specification](docs/SPEC.md) for pagination, output fields, and API limits, and the [official Payhip reference](https://payhip.com/api-reference) for provider details.
