# <img src="logo.png" height="20"> Booqable

Manage rental customers, product groups and variations, stock items, orders, and booking availability in Booqable. Book products, record pickups and returns, manage coupons, create payment records, review invoices and contracts, and queue customer emails from templates.

See [the API specification](docs/SPEC.md) for setup, tool coverage, and operational limits.
