# <img src="logo.png" height="20"> Kommo

Manage sales leads, contacts, companies, pipelines, and tasks in Kommo. Search CRM records, create and update entities, manage tags and entity links, add and list notes, and accept or decline incoming leads. Discover account identity, users, custom fields, pipeline stages, and lead loss reasons for follow-up operations. Review account events with entity, event-type, and date filters.
