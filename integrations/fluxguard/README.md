# <img src="logo.svg" height="20"> Fluxguard

Monitor web pages with Fluxguard. Add monitored pages, retrieve captured page data, start on-demand crawls, organize sites with categories, manage webhook endpoints, and delete monitored pages or sites. Read organization account details and sample change notifications. Category and nickname options apply when adding a page to a new site.
