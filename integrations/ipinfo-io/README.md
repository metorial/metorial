# <img src="logo.png" height="20"> IPinfo.io

Look up IPv4 and IPv6 geolocation, ASN and network flags, carrier details, and privacy detection. The current paid lookup API and maintained legacy format are available, alongside the free country-level Lite API. Custom API subscribers can retrieve ASN prefixes, abuse contacts, company IP ranges, and domains hosted on an IP.

The seven tools cover detailed IP lookup, Lite IP lookup, ASN lookup, abuse contact lookup, company IP ranges, hosted domains, and batch enrichment. Batch lookup accepts mixed endpoint or field patterns and supports the current paid, free Lite, and legacy batch APIs. Each query is billed according to its endpoint and plan.

Connect with an API token from [your IPinfo dashboard](https://ipinfo.io/account/token). Available data depends on your subscription. Omitting the IP in an IP lookup returns the public IP of the server performing the request; this does not identify your account or your device.

See the [API specification](docs/SPEC.md) for endpoint details and [IPinfo's documentation](https://ipinfo.io/developers) for current plan availability.
