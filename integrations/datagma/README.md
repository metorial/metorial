# <img src="logo.jpeg" height="20"> Datagma

Enrich B2B contact and company profiles with real-time data. Find verified work emails with Datagma’s current email API, or use the email lookup with domain-only and country options. Find mobile phone numbers from email or social profiles, detect job changes, look up contacts by phone or personal email outside the EU, find employees at companies, enrich Twitter/X profiles, and check credit balance.

Use an API key from [Datagma’s API settings](https://app.datagma.com/user-api). The API supports up to 10 requests per second; credit charges depend on the operation and results.

See the [tool and API reference](docs/SPEC.md) for supported inputs and response details.
