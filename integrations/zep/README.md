# Zep

Manage persistent memory and knowledge graphs for AI agents. Discover users and identify the project connected by your API key. Create and manage users, conversation threads, and message history. Ingest text and serialized JSON into user or shared graphs, then retrieve context or search nodes, facts, and episodes. Configure graph ontology and user summary instructions, and select existing context templates when retrieving context.
