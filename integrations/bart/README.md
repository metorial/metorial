# <img src="logo.png" height="20"> BART

Retrieve BART train departure estimates, plan trips, compare fares, and inspect station, route, and schedule information. Discover station and route identifiers, check service advisories and elevator bulletins, and read parking, bike-share, and accessible station directions. All tools are read-only.

This integration uses the [BART legacy JSON API](https://api.bart.gov/docs/overview/index.aspx). BART recommends GTFS and GTFS-RT for its currently supported transit data standards. Legacy holiday and special-notice commands are deprecated and are not included.

Provide a [BART API key](https://api.bart.gov/api/register.aspx). See [the API specification](./docs/SPEC.md) for tool coverage, input limits, and official documentation.
