# Cursor

Launch and manage Cursor cloud agents, follow their individual runs, and retrieve downloadable files. The current Cloud Agents API supports connected GitHub, GitLab, Bitbucket Cloud, and Azure DevOps repositories, as well as no-repository tasks. The existing GitHub v0 tools remain available during Cursor's migration window.

Enterprise administrators can discover team members, track daily usage and spending, set user limits, remove members, and manage repository blocklists. The current member and spending tools return encoded user IDs; their older numeric-ID tools are deprecated.

Use a user or service-account key for cloud agents, or an Enterprise Admin key with `admin:*` permissions for team tools. Cloud agent runs can incur charges. Current v1 agent/run endpoints are public beta.
