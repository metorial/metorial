# Keen.io

Collect, store, and analyze custom event data via API. Record single or batch events into collections, run analytical queries and funnel analyses, and extract full-resolution data. Compute multiple named metrics in one request with `run_multi_analysis`. Supports saved and cached queries, cached datasets, schema inspection, and access key management. Filter, group, and segment analyses by timeframe, interval, and property values.

Connect with a Project ID and its Master, Read, Write, or custom Access Key. Master Keys are required for administrative operations such as deleting events and managing Access Keys. Query and extraction results retain the provider's data objects. Access-key and cached-dataset lists support explicit pagination.
