# <img src="logo.svg" height="20"> Seqera

Manage Nextflow pipelines and workflow runs in Seqera Platform. Create, update, and delete saved pipelines; launch, monitor, and cancel runs; inspect task pages and logs; manage datasets, pipeline secrets, and resource labels; discover organizations and workspaces; list credential metadata and inspect compute environments; manage existing pipeline actions; and list workspace participants.
