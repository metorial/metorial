# <img src="logo.png" height="20"> Better Stack

Manage uptime monitors, heartbeats, incidents, status pages, on-call calendars and escalation policies. Configure telemetry sources and alerts, inspect dashboards, and download dashboard JSON backups. Manage incoming-webhook rules for creating, acknowledging and resolving incidents. Supports Uptime, Telemetry and Global API tokens.

Incident creation and enabled checks or alerts can notify people. Status pages can publish publicly; use published false for an unpublished page. See the [capability and API guide](docs/SPEC.md) for supported operations, team selection and provider limits.
