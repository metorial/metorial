# Super G̴͎̬̼̾̈́̍͠o̶͇͓̅̐̿o̷͍̓̓̄̚g̶͎̩̾̏l̸̛̬̓e̸̗̮͘ 2A specification

Work across Google Docs, Sheets, Slides, Forms, Calendar, Meet, Contacts, Tasks, Search Console, and Tag Manager through one Google OAuth connection.

The 128 tools include `get_calendar` for calendar properties, `list_calendar_sharing` for paginated sharing rules, `get_my_profile` for the connected account, and `update_account` for Tag Manager account settings.

All 47 requested OAuth scopes correspond to supported tool access. Read-only scopes are accepted by the corresponding read tools; broader grants remain alternatives where the provider supports them. Read permission does not authorize a write action.
