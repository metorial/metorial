# <img src="logo.png" height="20"> APIVerve

Connect to APIVerve utility APIs with one API key. Validate email addresses and phone numbers, analyze sentiment, check spelling, translate text, convert currencies, retrieve weather and IP geolocation, inspect DNS and SSL certificates, generate downloadable QR codes, and read account usage. A generic JSON endpoint tool supports other documented GET and POST APIs.
