# <img src="logo.png" height="20"> Rosette Text Analytics

Analyze text with Rosette Text Analytics, now Babel Street Analytics. Extract entities and relationships, determine sentiment, categorize documents, discover topics, and perform linguistic analysis. Match, translate, and deduplicate names across supported languages, and compare addresses or structured records. Generate text embeddings and transliterate Arabizi chat text into native Arabic script. Discover supported languages and source/target language pairs, check license status, and inspect the connected API service version.

Cloud connections require an API key from the [Developer Portal](https://developer.babelstreet.com/). On-premise installations can use the no-authentication connection option with their own API base URL. Language availability depends on the endpoint and installation; call `list_supported_languages` before choosing a language. See the [official API documentation](https://documentation.babelstreet.com/analytics/docs/analytics-overview).
