# <img src="logo.svg" height="20"> Lodgify

Manage vacation rental properties, reservations, and guest communication. Browse property listings, room types, rate add-ons, and payment settings. Create and update bookings with status tracking (open, booked, tentative, declined), record check-in and check-out times, set door key codes, and move bookings to the trash or restore them. Create and track pre-booking enquiries and work the combined bookings-and-enquiries inbox. Query and update availability calendars across connected channels. Set nightly rates and seasonal pricing. Generate quotes and payment links, and request payment from guests. Read message threads and send guest messages.
