# ProcFu

Automate Podio items and comments, discover organizations, workspaces, and apps, and trigger Podio Workflow Automation flows through ProcFu. Run saved ProcScript code, manage global variables, query connected MySQL databases, and send authenticated requests through configured OAuth services. Inspect the connected account, usage limits, and recent errors.

Connect with the API Auth Token from ProcFu’s Security & Keys page and allow the calling server’s IP address there. See the [integration specification](./docs/SPEC.md) for supported operations and official documentation.
