# Vapi

Build and manage voice AI assistants, calls, and multi-assistant squads. Configure reusable conversation tools, manage phone numbers and inbound SIP routing, upload text knowledge sources, schedule outbound campaigns, and retrieve call transcripts, analysis, and downloadable recordings or logs.
