# <img src="logo.png" height="20"> Wolfram Alpha API

Compute answers to mathematical and factual queries with Wolfram Alpha. Retrieve structured result pods, concise text answers, conversational phrases, downloadable result images, and LLM-oriented text. Refine full results using provider assumption and pod-state tokens, select result pods, and set a unit system or location context. Validate parsing and classify queries before computing full results.
