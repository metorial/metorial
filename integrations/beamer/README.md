# <img src="logo.png" height="20"> Beamer

Manage changelog posts and feature requests, inspect comments, reactions, votes, and NPS responses, and retrieve personalized feed URLs and unread counts.

Connect with an API key from **Settings > API**. Use `get_account` to check the connected product. See the [tool specification](docs/SPEC.md) for pagination, translations, and compatibility details.
