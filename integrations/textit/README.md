# TextIt

Manage contacts, groups, custom fields, and global variables. Send individual messages or multilingual broadcasts, start conversational flows, inspect run results and asynchronous status, configure campaign events, and assign, annotate, close, or reopen support tickets.

Read tools discover labels, fields, globals, topics, workspace users, broadcasts, flow starts, campaign events, channels, and current workspace identity. List tools return one page with `hasMore` and `nextCursor`; pass that cursor with the same filters to continue. Message media references remain metadata and are not downloaded by list tools.

Authenticate with a TextIt API token from your workspace API documentation page. The connection uses HTTPS at `https://textit.com/api/v2`.
