# <img src="logo.png" height="20"> Semantic Scholar

Search academic papers and author profiles, retrieve single or batch metadata, explore citations and references, and find related papers. Use relevance search for ranked results, bulk search for larger filtered collections, title matching for a known paper, or snippet search for relevant excerpts with source and license information.

The Academic Graph, Paper Recommendations, and Datasets tools are grouped separately. Public access and API key connections are supported; endpoint access and rate limits depend on the provider.

Discover dataset releases and retain their original temporary file URLs. To prepare one file for download, pass a URL from the dataset’s file list to `get_datasets` as `downloadFileUrl`, together with the release and dataset. Metadata reads do not prepare files. Selected files can be several gigabytes and remain subject to download and storage limits. Renewal preserves the selected dated release and exact dataset object; later file availability is not verified by preparation.
