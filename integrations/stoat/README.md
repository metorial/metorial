# <img src="logo.svg" height="20"> Stoat

Read, send, edit, search, pin, and delete messages in Stoat, formerly Revolt. Manage servers, channels, members, bans, roles, permissions, invites, custom emoji, and channel webhooks. Discover direct message channels with a user session.

Connect with a bot token or user session token. The default API for new connections is `https://api.stoat.chat`; provide your instance's API URL when connecting to a self-hosted deployment. Existing connections retain their saved API URL. Bot and session permissions determine which operations are available.

Messages and webhook avatars can reference files already uploaded to the provider. This integration does not upload files or manage bot accounts or friend relationships.
