# Red Circle API

Search and retrieve product data from Target (US retailer). Look up products by TCIN, DPCI, UPC, GTIN, ISBN, or URL. Search Target's inventory by product name, SKU, or UPC with sorting and filtering. Retrieve customer reviews, browse category listings, and localize results by US zip code for shipping and availability. Create, list, update and delete requests inside bulk collections of up to 15,000 requests, run collections on a schedule, and download JSON, JSON Lines or CSV results. Automatically upload results to Amazon S3, Google Cloud Storage, Azure, Alibaba OSS or S3-compatible storage. Inspect account identity, credit usage and service status.
