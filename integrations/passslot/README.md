# <img src="logo.png" height="20"> PassSlot

Create and manage mobile wallet pass templates, generate personalized passes, download signed `.pkpass` files, and share passes by distribution link or email. Read pass values, status, and the full pass description; update values and status; and send manual push notifications when needed. Inspect template verification actions and distribution restrictions, manage scanner configurations, and discover available pass type identifiers. Template branding and payment settings remain available through template updates where the account plan supports them.

Authenticate with a PassSlot App Key from the dashboard. Scanner operations require an App Key with full access. Resource lists return the provider’s complete array; the REST API does not document pagination controls.

See [the capability reference](docs/SPEC.md) and [PassSlot REST documentation](https://www.passslot.com/developer/api/resources).
