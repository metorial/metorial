# <img src="logo.png" height="20"> Gosquared

Track and retrieve real-time and historical web analytics data including visitors, pages, traffic sources, and campaigns. Identify and manage users in a People CRM with profile data, custom properties, smart groups, and paginated activity timelines. Track events, pageviews, and ecommerce transactions. Retrieve live chat messages, send agent messages, archive conversations, and leave internal notes. Discover accessible projects and inspect the API key's granted permissions.

Connect with a GoSquared API key. The project token is optional during setup so you can discover accessible projects with List Sites; set a project token before using analytics, tracking, People, or chat operations. API key permissions control which operations are available.
