# <img src="logo.svg" height="20"> Browse AI

Run trained Browse AI robots, retrieve captured text and tables, and download task data as JSON. Discover robots and bulk runs, inspect task history and retries, manage scheduled monitors, update session cookies, and configure webhook subscriptions.

Connect with an API key from the [Browse AI dashboard](https://dashboard.browse.ai/api). Robot IDs are discovered with `list_robots`; task, monitor, and bulk-run IDs come from their corresponding list tools.

Monitor tools support recurring schedules, change notifications, pause/resume, and deletion. The task-data download supports both inline captured data and the provider’s temporary URL for large results. Existing task tools continue returning structured captured data.

See the [API reference](https://docs.browse.ai/api/) and [capability details](docs/SPEC.md).
